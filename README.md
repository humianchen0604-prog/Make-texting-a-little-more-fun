# Make texting a little more fun

An iOS 26 Messages prototype with a working on-screen keyboard. Send a message to Cherry and two phrases get their own animated bubbles:

- **"I'm so tired…"** – a grainy blue bubble whose eyelid droops shut while pencil z's float away.
- **"I just woke up"** – a soft pink bubble that yawns, with a breath balloon swelling out of its mouth.

Anything else sends as a normal blue iMessage bubble.

Open `index.html` in a browser. No build step.
